생성형 AI 업무자동화 전문가과정 · 2차수 · 프로젝트 08 · v1.1 상세 기획안 방식

구매 절감 실적 자동 집계 — 발주 실적 × 담당자 × 예산 단가

엑셀 세 가지를 올리면 발주유형 ZNB 만 골라 협력사 코드로 담당자를, 자재품번으로 예산단가·NOTE 를 맞춥니다. 품목범주로 구매단가를 정해 차이금액·Impact·실적(인하/인상/동결)을 계산하고, 못 맞춘 행은 비고에 사유를 남겨 보고용 엑셀(실적·집계·제외·오류 내역)로 냅니다.

1. 엑셀 파일 세 가지를 올리세요

표 세 가지 — 발주 실적(구매오더·발주유형·협력사 코드·협력사 이름·자재품번·자재품명·통화·구매단가·발주수량·품목범주·조립비·자재비) · 협력업체 담당자(협력업체 코드·협력업체명·담당자) · 예산 단가(자재품번·예산단가·NOTE). 파일을 따로 올려도 되고 한 파일에 시트로 넣어도 됩니다. 머리글을 보고 어느 표인지, 어느 열이 어느 항목인지 짝짓고, 못 찾은 열은 아래에서 고릅니다.

예제 세 파일은 저장소 samples/ 폴더에도 있습니다. 예제 데이터는 실제 사내 데이터가 아닙니다.

2. 환율

기획안의 고정 환율이 기본값입니다(KRW 1 · USD 1,350 · EUR 1,572 · CNY 190 · JYP 9.4). 여기서 고치면 이 브라우저에 저장되고 바로 다시 계산합니다. JYP 는 원본 통화 코드가 JYP 일 때만 적용합니다. JPY 처럼 글자만 비슷한 코드는 바꾸지 않고 「환율 확인 필요」로 둡니다. 표에 없는 통화도 「환율 확인 필요」입니다.

3. 구매 절감 실적

정합성 검증

    담당자별

    협력사별

    구매오더별 상세

    구매단가 옆 구매단가 조립비는 품목범주로 고른 칸입니다(0 = 구매단가 그대로, 3 = 조립비). 예산단가 옆 예산 파일은 올린 문서의 값, 화면 입력은 여기서 넣은 값, 계산은 도구가 계산한 값입니다. 예산단가가 비어 있는 행은 그 자리에서 입력하면 바로 계산하고, 입력값은 이 브라우저에 품번별로 남습니다.

    화면에서 입력한 예산단가

    파일에 없는 품번에만 쓰입니다. 파일에 값이 있으면 파일 값이 우선이고, 다시 올리거나 다시 계산해도 여기 값은 지워지지 않습니다.

      제외된 행(발주유형 ZNB 아님)
      오류 내역(담당자 미매칭 · 예산단가 미매칭 · 구매단가 확인 · 환율 확인 · 기타)

      「구매절감 실적」 시트는 열 19개를 기획안 순서 그대로 두고, 구매오더 단위를 합치거나 빼지 않습니다. 예산단가가 빈 칸에 값을 넣으면 차이금액·Impact·실적이 수식으로 바로 계산됩니다. 담당자 미매칭 행은 이 시트에 없고 오류 내역 시트에 있습니다.

      4. 계산 기준

      • 분석 대상 — 발주유형이 ZNB 인 행만. 나머지는 「제외」 시트에 둡니다.
      • 담당자 — 협력사 코드가 협력업체 담당자 표의 코드와 정확히 같을 때. 앞뒤 공백·숫자/글자 형식만 맞추고 선행 0 은 지우지 않습니다(001001 과 1001 은 다른 코드). 못 맞추면 「미매칭」으로 표시하고 최종 실적에서 뺍니다.
      • 예산단가·Lever — 자재품번이 정확히 같을 때. 공백만 맞추고 하이픈·글자는 손대지 않습니다. 못 맞추면 행은 남기고 예산단가·차이금액·Impact·실적을 비운 뒤 비고에 「예산단가 미매칭 - 수작업 입력 필요」. Lever 는 예산 단가 표의 NOTE 를 해석 없이 그대로 씁니다.
      • 구매단가 — 품목범주 0 이면 발주 실적의 구매단가를 그대로, 3 이면 조립비. 자재비 열은 쓰지 않습니다. 그 밖의 범주이거나 값이 비었으면 계산을 보류하고 「구매단가 확인 필요」.
      • 차이금액 = 구매단가 − 예산단가 — 양수 인상 · 음수 인하 · 0 동결(구매단가가 예산단가보다 높으면 인상). v1.4 에서 기획자 정정대로 바꿨습니다(실적 구분은 차이금액 부호로 하고 Impact 부호로 하지 않습니다).
      • Impact = 차이금액 × 발주수량 × 환율 — 원화 기준 정수 반올림. 구매단가·예산단가·발주수량·환율 중 하나라도 없으면 Impact 를 내지 않습니다.
      • 비고 — 담당자 미매칭 · 예산단가 미매칭 - 수작업 입력 필요 · 구매단가 확인 필요 · 환율 확인 필요 · 기타 데이터 오류 중에서만 적고, 정상 행은 비워 둡니다. 원본 값은 고치지 않습니다.
