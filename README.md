# build-2611-08 · 구매가 절감 실적 집계

생성형 AI 업무자동화 전문가과정 **2차수** 수강생 프로젝트 08 — 기획 최상원.

**바로 쓰기: https://aebonlee.github.io/build-2611-08/**

월별 발주 실적과 연초 확정 단가표(엑셀)를 올리면 품번별 구매가 절감액을 계산합니다.
확정 단가가 없는 신규 품번은 품의서 정보(표로 올리거나 화면 입력)로 맞추고, 못 맞춘 품번은 「확인 필요」로 따로 모읍니다.
사유 Lever·업체·월별 실적을 그래프와 엑셀 보고서로 냅니다.
파일은 브라우저 안에서만 처리하며 서버로 올라가지 않습니다.

**v1.1 예산단가 방식** (`budget.html`): 기획자의 상세 기획안대로 발주 실적 · 협력업체 담당자 · 예산 단가 세 파일을 올리면 발주유형 ZNB 만 골라 담당자와 예산단가·NOTE 를 맞추고, 품목범주로 구매단가를 정해 차이금액·Impact·실적(인하/인상/동결)을 계산합니다. 열 순서가 고정된 보고용 엑셀(실적 · 집계 및 검증 · 제외 · 오류 내역 · 환율)을 냅니다. 예산단가가 없는 행은 화면이나 엑셀에서 직접 넣으면 바로 계산됩니다.

| 파일 | 역할 |
|---|---|
| `js/engine.js` | v1.0 계산 엔진(읽기·매칭·절감액·Lever·확인 필요·집계) — 판정은 전부 여기 |
| `js/app.js` | v1.0 화면 |
| `js/budget.js` | v1.1 계산 엔진(열 짝짓기·ZNB·담당자/예산단가 매칭·구매단가·차이금액/Impact/실적·비고·집계·엑셀 구성) |
| `js/budget-app.js` · `budget.html` | v1.1 화면 |
| `samples/` · `tools/make-samples.js` | v1.1 예제 파일 3종(가짜 데이터)과 생성 스크립트 |
| `test/logic.test.js` | 계산 규칙 테스트 `node test/logic.test.js` |
| `test/smoke.browser.js` | 화면 연기 테스트(playwright) |
| `CLAUDE.md` | 작업 지시서 + 기획서 원문 |

예제 데이터는 실제 사내 데이터가 아닙니다.
